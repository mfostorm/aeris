# ЛР1 (C#): как сделать скриншоты, ≈20 минут

В отчёте уже есть весь код и ответы на вопросы. Рисунки 1–6 — ваши. Осталось 15 скриншотов (рисунки 7–21). На их месте стоит жёлтая надпись «[ ВСТАВИТЬ СКРИНШОТ ]».

Код всех заданий лежит в папках `Task1` … `Task6` (файлы `Program.cs`). Он проверен: всё собирается и работает.

## Как запускать (в том же онлайн-компиляторе, где вы делали задания 1–2)

1. Откройте файл `Task3/Program.cs` (или возьмите код из отчёта), скопируйте **весь** код и вставьте в окно компилятора вместо того, что там было.
2. Нажмите **Run** и вводите данные в консоли, как в таблицах ниже. После каждого ввода нажимайте Enter.
3. Когда программа закончит работу и появится «[Execution Finished]», сделайте скриншот консоли: **Win + Shift + S**.
4. Для следующего тестового набора снова нажмите **Run**.
5. Для следующего задания вставьте код из `Task4/Program.cs` и т. д.

> Дробные числа в онлайн-компиляторе вводятся **через точку**: `9.8`, как в задании 2.
> Если у компилятора нет интерактивной консоли, а есть поле **STDIN / Input**, впишите туда все значения сразу, каждое с новой строки, и нажмите Run.

## Задание 6 — рисунки 16–21 (калькулятор, один запуск)

Вставьте код `Task6/Program.cs`, нажмите Run и делайте скриншот после каждого пункта (можно в одном запуске, можно перезапускать):

| Рис. | Что вводить |
|---|---|
| 16 | `1` → `10` → `+` → `5` (видны меню и результат 15.00) |
| 17 | `2` → `50` → `45` → `9.8` (дальность 255.10 м) |
| 18 | `3` → `5` → `4` → `4` (переведён) |
| 19 | `4` → `текст, с: точками.` |
| 20 | `5` → `6` (таблица 6×6) |
| 21 | `1` → `7` → `/` → `0` (деление на ноль), затем `9` (неверный пункт), затем `0` (выход) |

Если меню на скриншоте не помещается, прокрутите консоль или сделайте два скриншота.
