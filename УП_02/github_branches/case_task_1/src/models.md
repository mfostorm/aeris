# Модели бизнес-процессов ИС «Космос»

- IDEF0: контекстная диаграмма А-0 и три уровня декомпозиции;
- IDEF3: процесс бронирования номера;
- DFD: потоки данных между гостем, администратором, руководством, платежной системой и хранилищами D1–D3;
- UML: вариантов использования, деятельности, состояний, последовательностей, классов, компонентов, развертывания, пакетов.

Файлы диаграмм находятся в каталоге `docs`.
