# Чек-лист проверки диаграмм

- [x] у каждой функции IDEF0 есть вход, выход, управление и механизм;
- [x] декомпозиция не менее трех уровней;
- [x] DFD: все потоки связаны с процессами, хранилищами или внешними сущностями;
- [x] UML: связи include/extend на диаграмме вариантов использования;
- [x] диаграмма классов: атрибуты, методы, связи и наследование.
