# Спецификация ПО ИС «Космос» (кратко)

**Функциональные требования:** регистрация и авторизация, поиск свободных номеров, оформление и отмена бронирования, просмотр своих броней, управление бронированиями, номерным фондом и пользователями (администратор), хранение данных.

**Нефункциональные требования:** удобство использования, быстродействие, надежность, безопасность (ролевой доступ), совместимость, масштабируемость, поддерживаемость, адаптивность.
