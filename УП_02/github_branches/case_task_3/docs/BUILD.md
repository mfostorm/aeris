# Сборка и запуск GUI (C++ / Qt 6)

1. Установить Qt 6 и Qt Creator (Qt Online Installer, компоненты: Qt 6.x MinGW, Qt Creator, CMake).
2. В Qt Creator: «Файл → Открыть файл или проект» → `src/CMakeLists.txt`.
3. Выбрать комплект Desktop Qt 6 MinGW → «Собрать» → «Запустить».

Учетные записи: администратор `admin@kosmos.ru` / `admin123`, гость `guest@mail.ru` / `123456`.
База данных `hotel.db` (SQLite) создается автоматически рядом с программой.
Запуск с параметром `--screenshots папка` сохраняет изображения всех окон.
